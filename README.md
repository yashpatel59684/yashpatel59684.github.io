# GitHub Pages Deployment Guide

## Quick 1-Click Deployment
1. Make sure you have a GitHub repository created at:
   `https://github.com/new` with the name **`yashpatel59684.github.io`** (Public).
2. Double-click **`deploy-github.bat`** (or run `.\deploy-github.ps1` in PowerShell).
3. The script will stage, commit, and push everything automatically!
4. Your site will be live at:
   👉 **`https://yashpatel59684.github.io`**

## Enabling Pages in Repository Settings (First Time Only)
1. Go to your repo on GitHub: `https://github.com/yashpatel59684/yashpatel59684.github.io`
2. Click **Settings** (top tab) -> **Pages** (left sidebar).
3. Under **Build and deployment > Source**, select **Deploy from a branch**.
4. Select **Branch: `main`** and **Folder: `/ (root)`**, then click **Save**.
5. Wait ~60 seconds, and your portfolio will be live!
